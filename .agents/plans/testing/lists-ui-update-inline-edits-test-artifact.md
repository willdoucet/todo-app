## Affected Pages/Routes
- `/lists` — All task inline editing, expand/contract, add-task rows, mobile modal fallback

## Key Interactions to Verify

### TaskItem inline editing
- Click task text → input appears with current title, terracotta underline
- Type new title → Enter → title saved via PATCH, exits edit mode
- Escape → reverts to original title, exits edit mode
- Blur on non-empty title → auto-saves via PATCH
- Blur on empty title → cancels (reverts, no delete)
- Empty title + Enter → deletes task
- Save failure → input stays active, error toast shown
- Click checkbox while editing → auto-saves title, toggles complete, exits edit

### Expand/contract (desktop)
- Click expand chevron on desktop (≥640px) → panel slides open with date/desc/assignee/priority fields
- Each field change → debounced PATCH call (500ms)
- Multiple rapid changes to same field → single PATCH
- Expand chevron fills terracotta when active

### Expand/contract (mobile)
- Click expand button on mobile (<640px) → opens modal instead of inline panel

### Single edit enforcement
- Click task A (editing) then click task B → A auto-saves, B enters edit mode

### AddTaskRow
- "Add a task" row at bottom of unsectioned tasks → click → inline input appears
- "Add a task" row at bottom of each section → click → creates task with correct section_id
- "Add a task" in empty section → click → inline input with section context

### Toast system
- Toast appears on save error, auto-dismisses after timeout
- Multiple errors show stacked toasts

### Action area (TaskActionArea)
- Delete button always visible (no hover-reveal)
- Save/Cancel buttons appear only when editing
- Priority flag and due date indicators render correctly

## Edge Cases
- Delete-on-empty-enter when task is iCloud synced (should still delete)
- Expand panel with no family members loaded yet (graceful empty state)
- Very long task title in inline edit (text should not overflow)
- Task with subtasks → expand chevron for subtasks vs expand button for details (two different expand controls)
- Completed task in edit mode → line-through removed during editing, reapplied after save
- Rapid click between multiple tasks → only one enters edit mode, previous auto-saves

## Critical Paths
- Create task → edit title inline → expand → set due date + priority → contract → verify saved
- Edit existing task → clear title → Enter → confirm deletion
- Mobile: edit title inline → tap expand → modal opens with correct fields → save in modal → return to list
