## Key Interactions to Verify

### Phase 1
- Set task priority (None/Low/Medium/High) via TodoForm on `/lists`
- Create section within a list — section header appears, tasks grouped under it
- Edit/delete section — inline controls on SectionHeader
- Reorder sections — POST reorder endpoint
- Create subtask — "Add Subtask" pre-fills parent_id, child renders indented
- Expand/collapse subtask tree — toggle on TaskItem

### Phase 2
- "Connect Reminders" on existing iCloud card → validates credentials (no re-login) → shows ReminderListSelector → connect
- Sync Now for reminders → triggers immediate pull
- Toggle complete on synced task → pushes to iCloud
- Edit synced task title → pushes to iCloud
- Delete synced task → pushes delete to iCloud
- Disconnect Reminders → tasks remain local, sync metadata cleared

## Edge Cases

### Phase 1
- Cycle detection: task A → B → C → A must return 400
- Cross-list parent: parent in List 1, child in List 2 → 400
- Section-list mismatch: section from List 1 assigned to task in List 2 → 400
- Delete section → tasks in section get section_id=NULL (not deleted)
- Subtask depth: 3+ levels deep → only 2 levels eager-loaded, deeper lazy

### Phase 2
- VTODO with no DUE date → task.due_date=NULL (most common case)
- VTODO with no SUMMARY → skip, don't create broken task
- VTODO with no UID → skip
- Duplicate external_id race (concurrent sync) → upsert or catch UniqueViolation
- Push fails all 3 retries → task stays PENDING_PUSH, no data corruption
- Synced list delete attempt → 400 with "Disconnect in Settings" message
- Disconnect while tasks have PENDING_PUSH → clear metadata, cancel pending pushes
- Calendar sync OK but reminders sync fails → separate status badges

## Critical Paths
- Create task with priority → verify priority persisted and displayed correctly
- important=True migration → verify becomes priority=1
- Full reminders round-trip: iCloud → pull → edit locally → push → pull again → verify
- Completion round-trip: complete in app → push → pull → still completed
- Subtask sync: RELATED-TO in VTODO → parent_id FK resolved after two-pass
- Disconnect flow: disconnect reminders → tasks remain usable → re-connect → tasks don't duplicate
