## Affected Pages/Routes
- `/mealboard/recipes` (Recipes tab) — card grid, list view, toolbar, tag filters, image upload

## Key Interactions to Verify

### Recipe cards (grid view)
- Cards render at 5 per row on desktop (≥1100px), do NOT stretch on partial rows
- Card shows gradient placeholder when no `image_url` — no letter, no emoji, just gradient + ghosted pot icon
- Card shows uploaded image when `image_url` is present
- Favorite heart floats top-right with drop-shadow, no white circle background
- Unfavorited: white outline heart. Favorited: filled red (#E06B6B)
- Hover: card lifts -3px, edit/delete icons fade in top-left
- Click card → RecipeDetailDrawer opens
- Staggered entrance animation on first load, capped at 800ms total delay

### Recipe rows (list view)
- Row shows gradient-colored dot + name + metadata + heart
- Hover: row highlights, edit/delete fade in
- Click row → RecipeDetailDrawer opens
- Last row has no bottom border

### Toolbar
- Search input with magnifying glass icon (mirrors Food Items pattern)
- Grid/list toggle: switching view persists in localStorage
- Recipe count badge: "12 recipes" or "3 of 12" when filtered
- Sort pill dropdown: A-Z, Z-A, Newest, Cook Time
- "+ Add Recipe" button opens RecipeFormModal

### Filter pills
- Favorites row: All / Favorites / Non-Favorites — active pill filled terracotta
- Tag chips row: extracted from recipe tags, multi-select, "Clear all" link
- Filters combine: search + favorites + tags all applied simultaneously

### Image upload (in RecipeFormModal)
- Upload area with camera icon → click opens file picker
- Upload success: preview thumbnail appears, "Change" and "Remove" buttons
- Upload error: inline banner with specific message (file too large / wrong type)
- Remove button clears image_url
- URL text input is removed (upload only)

## Edge Cases

### Grid layout
- 1 recipe: single card, left-aligned, not stretched
- 0 recipes: empty state with 🍳 + "No recipes yet" + CTA button
- 50+ recipes: stagger animation capped at 800ms (last cards animate together)
- Responsive: 5 cols → 4 → 3 → 2 → 1 at breakpoints 1100, 800, 500, 400px

### Filters
- Search + favorites + tags combined: "chicken" search + "Favorites" + "dinner" tag → intersection
- All tags cleared: "Clear all" returns to unfiltered view
- No tags on any recipe: tag row hidden entirely
- Filter to zero results: shows "No recipes match your filter" with different subtitle than zero-recipes state

### Image upload
- Upload 6MB file → rejected "File too large (max 5MB)"
- Upload .exe → rejected "Invalid file type"
- Network error mid-upload → error banner
- Edit recipe with existing image → preview shows, "Change" and "Remove" available

### View toggle
- Switch to list → localStorage updated → navigate away → come back → still in list view
- Switch views while search is active → filtered results maintained in new view

## Critical Paths

1. **Browse → discover → plan flow:**
   Open /mealboard/recipes → scan card grid → click a card → drawer opens → read recipe → close drawer → click a different card. Drawer should open fresh each time.

2. **Upload → save → see flow:**
   Click Add Recipe → fill name + instructions → upload image → see preview → save → new card shows uploaded image instead of gradient.

3. **Filter → find → open flow:**
   Type "chicken" in search → 3 results shown → count badge says "3 of 12" → click tag "dinner" → narrows to 1 → click card → drawer opens with correct recipe.
