## Affected Pages/Routes
- `/mealboard` (Meal Planner tab) — Jump to Current Week button visibility, cooked pulse animation
- `/mealboard` (Food Items tab) — card redesign (layout, stripe, sizing), emoji picker swap
- `/mealboard` (any tab triggering delete) — undo toast auto-dismiss bug
- Item create/edit modal — emoji picker, Cmd+S shortcut, first-error focus
- Task create/edit modal — Cmd+S shortcut

## Key Interactions to Verify
- Jump to Current Week button appears only when viewing a non-current week, disappears when on current week
- Jump to Current Week button has primary terracotta fill matching Add Item button style
- Emoji picker opens with search bar, typing filters emojis, recently-used row appears after first pick
- Clear button above emoji picker clears selection and closes picker
- Food item cards fill container width with responsive column count (not centered with max-width)
- Category indicator is a right-side vertical stripe (not a dot)
- Undo toast auto-dismisses at 15 seconds after appearing
- Cmd+S (Mac) / Ctrl+S (Windows) submits the form in ItemFormModal and TaskFormModal
- Escape still closes modals after shortcut handler is added
- Save with field errors moves focus to the first invalid input
- Cooked pulse animation plays once when marking a meal as cooked (motion-safe only)

## Edge Cases
- Jump to Current Week button at midnight boundary (week changes but no re-render)
- Emoji picker opened then dark mode toggled (theme stale until reopen — accepted)
- Emoji picker lazy load fails (network error) — ErrorBoundary shows Retry button; clicking Retry re-attempts import
- Undo toast when tab is backgrounded during 15s window — should dismiss on tab return
- Food item cards at extreme viewport widths: 375px (1 col), 768px (~2 col), 1300px (~3 col), 1600px (~4 col), 1920px
- Cmd+S when form has validation errors — should trigger first-error focus, not silent submit
- Cards with very long names — text should not overflow or break the stripe layout
- Empty food items grid — no layout shift when first card is added

## Critical Paths
- Delete food item -> undo toast appears -> wait 15s -> toast auto-dismisses (the bug fix)
- Open item modal -> open emoji picker -> search for emoji -> select -> save item (emoji-mart happy path)
- Navigate to future week -> see Jump to Current Week button -> click -> returns to current week -> button disappears
- Mark meal as cooked -> see pulse animation -> card settles into cooked state (line-through + sage)
- Open item modal -> trigger save with missing name -> focus jumps to name input -> fix error -> Cmd+S to save
- ErrorBoundary retry path: open item modal -> open emoji picker -> simulate chunk load failure -> see "Retry" button -> click Retry -> picker loads successfully
- Cooked toggle direction guard: mark cooked (pulse fires) -> unmark cooked (NO pulse fires)
