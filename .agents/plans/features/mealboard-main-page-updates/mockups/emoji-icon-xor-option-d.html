Design notes

  • Single row for icon + tabs. Square and tabs share one 42px-tall row. Tabs are 11px/tight padding. Total added height over the current modal is one row.
  • Two paths into Custom image. File upload — click the square. URL paste — type into the input that appears below the tabs. Both write the same icon_url field.
  • URL input is contextual. It only renders when the Custom image tab is active. In Emoji mode it disappears.
  • XOR stays visual. One square holds one thing. Switching tabs with content already set triggers the plan's discard-warning. Matches backend XOR constraint.
  • Keyboard & a11y. Tabs use role="tablist" + arrow keys. Square + URL input are separate tab stops. URL input has type="url" for native validation.
