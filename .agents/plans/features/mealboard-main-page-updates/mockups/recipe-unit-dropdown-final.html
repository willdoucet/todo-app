Recipe Units — Final: Smart Search Combobox

A searchable combobox that replaces the native select. Users can click to browse all units (shown grouped with color-coded category tags), or start typing to instantly filter ("tb" narrows to "tbsp", "cl" narrows to "clove"). Full keyboard navigation with arrow keys, Enter to select, Esc to close. The "(no unit)" option sits at the top of the full list. Two states are shown above: row 2 demonstrates a filtered search for "cl", and row 4 shows the full unfiltered dropdown. Pros: fastest for keyboard-heavy users, scales well if more units are added later, accessible with proper ARIA roles. Cons: requires a custom combobox component (Headless UI Combobox or similar), more implementation effort than native select.
