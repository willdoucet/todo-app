# Design: Recipe Card Redesign + Recipes Page Toolbar & List View

## Problem Statement

The recipes page has three UX problems:

1. **Recipe cards are too large and stretch on partial rows.** With 2 recipes, cards balloon to ~600px wide. The 4:3 gradient placeholder with a giant letter and emoji dominates the card and adds no value.
2. **The toolbar doesn't match the Food Items tab.** Food Items has a clean search + grid/list toggle + add button pattern. Recipes has a separate header bar with disconnected `<select>` dropdowns for filter and sort. The inconsistency is jarring.
3. **No list view for recipes.** Food Items has grid/list toggle. Recipes is grid-only. For quick scanning ("what recipes do I have?") a compact list is faster.

## What Makes This Cool

The interactions. Hover lift on cards, floating Airbnb-style hearts with drop-shadows, the drawer sliding in from the right, staggered card entrance animations. The page should feel polished and alive — like a real recipe app, not a side project. When someone looks over your shoulder, they say "whoa" because of how it *moves*, not just how it looks.

## Constraints

- Must use existing stack: React 19 + Tailwind v4 + Headless UI
- All colors from existing `@theme` tokens in `index.css`
- Must work in dark mode
- RecipeDetailDrawer (built in Phase 2) must be reused — card click and row click both open it
- Card spec locked: Option D from `mockups/recipe-card-spec.md`
- No new backend endpoints needed (existing `/recipes` and `/upload/recipe-image` APIs sufficient)
- All dev via Docker Compose

## Premises

1. The recipes page should mirror the Food Items toolbar pattern — search bar with magnifying glass icon, grid/list toggle, + Add Recipe button, all in one row. No category filter chips.
2. Grid view uses the Option D spec (5 per row max, 16:9 gradients, Airbnb heart, compact text). List view is a new addition.
3. The existing `<select>` dropdowns for filter/sort are replaced by the new toolbar pattern. Favorite filter becomes pills below the search bar. Sort stays as a compact dropdown in the toolbar.
4. RecipeDetailDrawer integration stays — clicking a card in grid OR a row in list view opens the drawer.

## Implementation Steps

### Step 1: recipeGradients.js — Shared gradient utility

New file: `frontend/src/constants/recipeGradients.js`

Extract the gradient hash function and preset arrays so RecipeCard and RecipeRow can share them without duplication:
- `GRADIENT_PRESETS` — 6 light/dark gradient pair objects
- `getRecipeGradient(name, isDark)` — hash name → pick gradient CSS string
- `getRecipeDotColor(name, isDark)` — returns the second (darker) color from the gradient pair (for RecipeRow dots)

### Step 2: RecipeCard.jsx — Implement Option D spec

**Reference:** `mockups/recipe-card-spec.md`

Rewrite `RecipeCard.jsx` to match the locked spec:
- 12px rounded corners, `#E8E2D9` border
- 16:9 aspect ratio image area
- **With image:** `<img>` with `object-fit: cover`, fills the 16:9 area
- **Without image:** Gradient placeholder via `getRecipeGradient()`. Center a 22px pot SVG at 16% opacity. **No letter. No emoji.**
- Floating heart top-right: Airbnb-style, 16px SVG, white stroke + drop-shadow unfavorited, filled `#E06B6B` favorited
- Hover actions: edit/delete icons fade in top-left, 14px SVGs with drop-shadow, `opacity: 0 → 1`, `transition: 180ms`
- Content: name at 13px/600, 2-line clamp. Metadata at 11px muted: `⏲ {totalTime}m · {servings} servings` where `totalTime = prep_time_minutes + cook_time_minutes`
- Hover: `translateY(-3px)`, ambient shadow
- Staggered entrance: accept `index` prop, apply `animation-delay: Math.min(index * 40, 800)` with `recipe-card-enter` keyframe. **Only animate on initial mount** — use a `useRef` flag to skip animation on subsequent re-renders (prevents re-animation on favorite toggle or filter change).
- Click card → calls `onClick` prop (parent opens drawer)
- `cursor: pointer`, `tabindex="0"`, Enter key triggers click

**Props:** `recipe`, `index` (for stagger), `onClick`, `onEdit`, `onDelete`, `onToggleFavorite`

### Step 3: RecipeRow.jsx — New list view row

New component for list view. One recipe per row in a bordered list container.

```
┌──────────────────────────────────────────────────────────────┐
│  [●]  Recipe Name          ⏲ 35m · 4 servings  ♡  [✎] [🗑] │
├──────────────────────────────────────────────────────────────┤
│  [●]  Recipe Name          ⏲ 25m · 4 servings  ❤           │
└──────────────────────────────────────────────────────────────┘
```

- Row padding: `px-4 py-3`, flex layout with `gap-3`, `items-center`
- Left: small colored dot — 8px circle, color from `getRecipeDotColor(recipe.name)`
- Name: 14px/500, `text-primary`, single-line truncate, `flex-1`
- Metadata: right-aligned, 12px muted, `⏲ {totalTime}m · {servings} servings`
- Favorite heart: 16px inline SVG. Unfavorited: `text-muted` stroke, favorited: filled `#E06B6B`. `onClick` with `stopPropagation`.
- Hover: row bg → `bg-warm-beige/50 dark:bg-gray-700/30`. Edit/delete icons fade in (14px SVGs, `opacity: 0 → 1`, `transition: 180ms`) to the right of the heart.
- Click row → opens RecipeDetailDrawer
- Border: `border-b border-card-border dark:border-gray-700` between rows. Last row: no bottom border. Outer container: `rounded-xl border border-card-border`
- Keyboard: `tabindex="0"`, Enter key triggers `onClick`, `cursor-pointer`
- Staggered entrance: `animation-delay: Math.min(index * 25, 500)`. Same initial-mount-only guard.

**Props:** `recipe`, `index`, `isLast`, `onClick`, `onEdit`, `onDelete`, `onToggleFavorite`

### Step 3.5: RecipeImageUpload.jsx + RecipeFormModal integration (EXPANSION)

**New sub-component: `RecipeImageUpload.jsx`** (~60 lines) — extracted per eng review to keep RecipeFormModal under 500 lines.

**Props:** `imageUrl`, `onImageChange(url | null)`

**States:**
- **No image:** Dashed border upload area with camera icon + "Upload image" text. Click to open file picker.
- **With image:** Preview thumbnail (16:9 aspect, rounded corners) + "Change" and "Remove" buttons below
- **During upload:** Upload button disabled, inline spinner + "Uploading..."
- **On success:** calls `onImageChange(url)`, preview shows the uploaded image
- **On error:** Inline banner below upload area: `bg-terracotta-50 border-terracotta-200 text-terracotta-700` with specific message ("File too large (max 5MB)" or "Invalid file type — use JPG/PNG/GIF/WebP")
- **Remove:** calls `onImageChange(null)`

Uses existing `POST /upload/recipe-image` endpoint.

**RecipeFormModal integration:** Replace the existing `image_url` text input (line ~335) with `<RecipeImageUpload imageUrl={form.image_url} onImageChange={(url) => setForm({...form, image_url: url})} />`. Remove the URL text input entirely (eng review decision: upload-only, no paste-URL fallback).

### Step 4: RecipesView.jsx — Toolbar + grid/list + tag filters + animations

Rewrite the `RecipesTab` function inside `RecipesView.jsx`:

**State additions:**
- `view` — 'grid' | 'list', initialized from `localStorage.getItem('recipe_view_preference') || 'grid'`
- `selectedTags` — `Set<string>`, multi-select for tag filtering

**Toolbar (single row):**
- Search input with magnifying glass icon (mirrors Food Items pattern)
- Recipe count: `"12 recipes"` or `"3 of 12"` when filtered — `text-xs text-muted`
- Grid/list toggle (same pattern as Food Items)
- Sort pill dropdown: "A-Z ▾" / "Z-A ▾" / "Newest ▾" / "Cook Time ▾"
- "+ Add Recipe" button (terracotta primary)

**Filter rows (below toolbar):**
- Row 1: Favorite pills — `All` / `Favorites` / `Non-Favorites` — same styling as Food Items category pills
- Row 2 (if tags exist): Tag chips — extracted from `recipes.flatMap(r => r.tags || [])`, deduplicated, sorted alphabetically. Clickable pills. Multi-select: selected tags are terracotta-filled, unselected are outlined. "Clear all" link when any selected.

**View toggle persistence:**
- On toggle: `localStorage.setItem('recipe_view_preference', newView)`

**Grid view:**
- `grid-template-columns: repeat(5, 1fr)` with `max-width: 1400px` + `mx-auto`
- Responsive: 4 cols at <1100px, 3 at <800px, 2 at <500px, 1 at <400px
- Cards rendered with `index` prop for stagger

**List view:**
- Bordered container (`rounded-xl border-card-border`), RecipeRow components inside
- Rows rendered with `index` prop for stagger

**View transition:**
- Grid↔list swap: outgoing view unmounts immediately, incoming view fades in over 150ms via `view-crossfade` animation class

**Skeleton loading:**
- Grid: 10 skeleton cards (16:9 shimmer + name bar + meta bar, `animate-pulse`)
- List: 6 skeleton rows (dot + name bar + meta bar, `animate-pulse`)

**Empty state:**
- Icon: `🍳` at text-3xl, muted
- Headline: "No recipes yet" or "No recipes match your filter"
- Body: contextual subtitle
- CTA: "+ Add Recipe" button (only when zero recipes total)

**Filter + search + sort logic:**
```
filteredRecipes = recipes
  .filter(r => !searchQuery || r.name.toLowerCase().includes(q))
  .filter(r => filterFavorite === 'all' || (filterFavorite === 'yes' ? r.is_favorite : !r.is_favorite))
  .filter(r => selectedTags.size === 0 || r.tags?.some(t => selectedTags.has(t)))
  .sort(sortFn)
```
